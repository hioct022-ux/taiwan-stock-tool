## 2026-06-12（上午）

### Signal 11：選擇權 P/C 比率
- 資料來源：TAIFEX pcRatioDown（Big5 CSV）
- 新增 `options_pc_ratio` 資料表
- `fetcher.py`：`fetch_options_pc()` + 歷史補抓
- `github_sync.py`：匯出 `options_pc.json`
- 大盤分析顯示 P/C 柱狀圖（顏色依值）+ 20 日 MA + 歷史百分位評分
- 百分位 >90% → Bull +1（恐慌底部），<25% → Bear +1（過度樂觀）

### 大盤評分顯示
- 大盤分析頁頂部新增評分卡（0–100 分）
- 公式：`ms = max(0, min(100, 50 - net * 5))`
- 分級：≥85 強烈偏多、70–84 偏多、55–69 中性偏多、45–54 中性、35–44 中性偏空、<35 偏空

### 估值分析頁籤（新增）
- 個股詳細頁新增「📈 估值分析」頁籤（共 7 個頁籤）
- Section 1：歷史 PE/PB 百分位，含走勢圖與四分位參考線
- Section 2：三情境合理價格試算（悲觀 / 合理 / 樂觀 PE × EPS）
- 用戶可自行調整 PE 與 EPS 假設

### 評分權重調整
- 技術面：35% → 40%
- 籌碼面：25% → 35%
- 基本面：40% → 25%
- 強化短線預判能力

## 2026-06-10 以前

### 主要架構
- 本機 SQLite + APScheduler 每日 16:30 自動抓資料
- `github_sync.py`：匯出 JSON → git push → Streamlit Cloud 唯讀
- `IS_LOCAL` 旗標切換本機 / 雲端模式

### 大盤分析（Signal 1–11）
- Signal 1–8：昨日資料（融資融券、期貨、T86、BIAS、布林、大盤PE、自選股強弱）
- Signal 9：即時外部市場（S&P 500、Nasdaq、SOX、TSM ADR、VIX）
- Signal 10：斷頭 / 多殺多風險評估（融資餘額變化）
- Signal 11：選擇權 P/C 比率（2026-06 新增）

### 個股評分系統
- 技術面（MA、RSI、KD、MACD、布林帶、BIAS）
- 基本面（EPS 趨勢、PE、PB、殖利率）
- 籌碼面（外資、投信、董監、外資持股比例）
- 綜合評分 0–100，≥80 強力買進，≥65 偏多操作

### 回測系統（backtest_stocks.py）
- 策略 A：無大盤過濾，基準
- 策略 B：大盤偏空不進場
- **策略 C（採用）：B + 到期續抱（評分 ≥65 續持10日），EV +10.20%，勝率 60.6%**
- 策略 D：B + 大盤轉空提前出場（不採用，EV 最差）
- 持有天數掃描：10 日有最佳勝率
- 停損掃描：8% 停損為最佳，無移動停利（多頭市場中移動停利反而有害）
